2. measure before claiming speed

a stopwatch needs a label. these earlier measurements belong to the laptop on 28 september, not the relay host. a cold process includes startup and provider time.

both runs used the same no-tool prompt and returned ok with exit code zero. the warm path was slower in this sample. provider variance was uncontrolled. one trial does not establish a typical latency or a speedup.

measurement method

prompt: Reply with exactly OK. Do not use tools.

cold: opencode run --format json. warm: opencode run --attach http://127.0.0.1:4096 --dir <workspace> --format json. authentication stayed in the host environment. elapsed time covers the complete command.
