Speaker Notes

reverse-engineering client binaries

extracting ground-truth design tokens from mobile apks to eliminate Figma specification drift and build hardware-accurate prototypes.

1. the multi-surface drift crisis

The Figma canvas is an illusion. As features ship week after week, the production app diverges. New gradient stops are hardcoded, custom Android drawables are patched into native builds, and the design file becomes an out-of-date artifact.

  • Sprint Alignment Friction: Resolving inconsistent paddings and mismatched hex tokens takes valuable sprint time.
  • Stakeholder Review Latency: Executives cannot evaluate static screenshots; they demand real interactive prototypes on physical hardware.

2. the extraction workflow

Instead of guessing styles by eye, we built a script to extract design tokens directly from the Android APK, pulling vector graphics, fonts, and hex colors straight from the production build.

The fastest, most accurate source of truth is not the design tool: it is the compiled binary currently running in production.

3. technical execution

A. Converting VectorDrawables into Standard SVG: Our python extractor parses the XML tree, maps viewportWidth to viewBox, and translates color resource references into inline SVG paths.

B. Typography & Tier Badges: We pull the exact font files shipped in the APK's assets/fonts/ directory. Brand-critical assets are extracted as clean, lossless vectors.

C. Hardware-Accurate Mobile Shell: On desktop screens, the prototype automatically mounts inside an authentic iPhone/Pixel hardware frame. On physical mobile devices, the shell collapses.

4. practical benefits

Moving from static mockups to interactive prototypes grounded in extracted production tokens provided two clear operational benefits.

Hardware-Accurate Mobile Previews

Stakeholders test features directly on physical smartphones with realistic touch targets, navigation bars, and modal sheets.

Reduced Design Token Drift

Prototypes share the exact color variables, font families, and vector drawables already shipped in the Android APK.

5. bridging design and production code

Effective product work isn't about writing vague documents and tossing tickets over a wall. It's about bridging the gap between design and engineering with real code, clear requirements, and working prototypes that stakeholders can actually try.
