prd_decision_tree.flow

How I Turn Human Frustration Into Permanent Code

A real PRD isn't just fluffy text boxes—it is an unambiguous logic tree that handles errors, isolates root causes, and guarantees safety before software touches real users.

● TRIGGER User Distress Signal Detected (Flight Delays, Ticket Errors, or Exam Crash)
↓
◇
DECISION 1: Is this an isolated one-off error or a systemic pattern?
✕ IF NO (Isolated Noise <1%):
Trigger automated self-serve resolution guide, issue instant FAQ help, and log ticket telemetry.
✓ IF YES (Systemic Friction >5%):
Escalate to Root Cause Deep Dive: audit API payloads, tax rules, and user journey drop-offs.
↓
[PROCESS 02] Trace Root Cause Across Domain Boundaries
Find where the real-world disconnect happens. (e.g. airline fare codes vs Indonesian regulation PM 185, or corporate marketing spreadsheets vs ERP invoicing).
↓
◇
DECISION 2: Does the fix require crossing departmental or company silos?
✓ IF YES (Cross-Silo Friction):
Form autonomous cross-functional squad (Product + Eng + Ops + Finance). Establish strict, unambiguous API contracts so neither side can break calculations.
✕ IF NO (Single Service):
Deploy targeted rule parser update directly to the calculation engine with regression tests.
↓
◇
DECISION 3: Automated Verification Gate: Zero Disputes & 100% Reconciliation?
✕ IF FAIL (Discrepancy Found):
Auto-quarantine in sandbox staging, flag breaking diff to on-call squad, and abort release.
✓ IF PASS (99.9%+ Accuracy):
Canary release to 5% live users, monitor real-time dispute metrics, then auto-expand to 100%.
↓
✔ RESOLUTION Resilient System in Production (Zero manual spreadsheets, cut user anxiety in half)

3M PHB Bio-Mask: 100% Biodegradable PPE

Billions of plastic medical masks pollute our oceans and take 450+ years to break down. We engineered a surgical mask from bacterial biopolymers (PHB) grown on Indonesian sugarcane waste that safely composts in soil in 90 days.

Schneider HotSand: Storing Solar Heat in Sand

Imported lithium batteries are expensive and degrade fast in humid tropical climates. HotSand stores excess daytime solar energy in superheated local silica sand beds to provide hot water, crop drying, and clean power overnight.
